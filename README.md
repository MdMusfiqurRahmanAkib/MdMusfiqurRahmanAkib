### KrishiBondhu

A weather-based crop advisory and market price comparison app for farmers. It combines
weather forecasts, plain-language crop advice, nearby market prices, price alerts and
task reminders in a bilingual English and Bangla interface. Built with Flutter and a
Node/Express/Prisma backend for cross-device sync.

Repository: https://github.com/MdMusfiqurRahmanAkib/krishibondhu
